## 10-12 项目启动:从环境搭建到模型跑通

这一天开始把代码提交到 GitHub,当天完成 8 次提交,按实际顺序是:

1. **环境搭建**(第 1 次提交)。机器上原有 Python 3.14 没有对应的 PyTorch 安装包,
   因此用 uv 建立了 Python 3.12 的独立环境。显卡是 RTX 5060(算力 sm_120),
   必须用 CUDA 12.8 以上的构建版本,所以在 `pyproject.toml` 里单独配置了
   PyTorch 官方 CUDA 12.8 源,并写了环境自检脚本确认显卡可用。
2. **数据集下载与校验**。下载 GTSRB 训练集 26640 张、测试集 12630 张,
   三个压缩包全部通过官方 MD5 校验。
3. **数据抽样预览**。先写了一个脚本把样本拼成网格图,确认数据内容与尺寸情况。
4. **项目计划**。写下选题说明、考核要求对照、创新点和提交计划。
5. **数据统计分析**。用 Pandas 汇总 43 个类别的标注文件,得到两个关键结论:
   类别不平衡(每类 150~1500 张,相差 10 倍,19 个类别不足均值一半);
   图片尺寸不统一(中位数仅 43 像素,82.1% 的短边不足 64 像素)。
   据此确定统一输入尺寸为 64x64,并把类别不平衡做成一组对照实验。
6. **手写残差块与 ResNet**。自己实现基础残差块与网络主体,没有调用现成模型;
   针对 64x64 的小尺寸输入,去掉了官方版本开头用于降采样的 7x7 卷积与最大池化。
   ResNet-18 配置下参数量 11.19M。
7. **训练、评估与推理流程**。实现训练循环、余弦学习率、
   按验证准确率保存最佳权重、训练曲线绘制,以及推理与 Grad-CAM 脚本。
8. **基线训练完成**。20 轮,耗时约 15 分钟,验证集准确率 100%。

### 遇到的问题

1. **git 推送被重置**。浏览器能正常访问 GitHub,但 git 推送报
   `Connection was reset`。原因是 git 不读取 Windows 的系统代理设置,
   而本机需要通过本地代理才能连上 GitHub。解决办法:只给 github.com 配置代理,
   避免影响国内仓库。
2. **数据集下载卡死**。torchvision 自带的下载函数长时间停在 0 字节,
   改用 curl 后速度达到 17 MB/s。教训是遇到网络类工具不要死等,及时换方案。
3. **检查点加载失败**。PyTorch 2.6 起 `torch.load` 默认只信任张量与基本类型,
   而检查点里存了 numpy 标量,导致加载被拒绝。解决办法是保存时显式转成
   Python 原生类型,并在加载时保留安全模式优先、异常时回退的处理。

## 10-13 实验与文档

这一天的重点是把实验做完整,并补齐文档。

1. **测试集评估与多组对比**(6 次提交中的前几条)。补齐了逐类准确率、
   混淆矩阵、多组实验对比图,以及只看最终精度会漏掉的收敛速度对比。
2. **完成六组对照实验**,在官方测试集上统一评估:
   基线 98.71%,关闭数据增强 97.92%,类别加权损失 98.26%,
   去掉跳跃连接 98.65%,34 层带跳跃连接 97.74%,34 层去掉跳跃连接 97.92%。
3. **补充 34 层深层对照实验**。为训练脚本增加了可配置的网络深度,
   结果发现残差连接的差距在 34 层上明显放大:稀有类别平均准确率相差
   6.28 个百分点,末轮验证损失相差约 5 倍。
4. **撰写项目说明文档**,包含选题、数据统计、技术方案、六组实验结果、
   创新点与局限。
5. **推理与可解释性结果入库**。把预测结果图与 Grad-CAM 热力图
   整理到 `docs/figures/` 并在文档中引用。

### 遇到的问题

1. **消融实验的模型结构不匹配**。去掉跳跃连接的模型没有 1x1 投影层,
   加载权重时报键名缺失。解决办法是让加载函数根据权重里有没有 `downsample`
   自动判断结构。
2. **对比图取错了"稀有类别"**。绘制"最稀少 15 个类别"时误用了固定的
   类别编号 0-14,而这批编号里混着样本最多的类别,会让结论完全反过来。
   改为按样本数排序后动态选取,并核对了两组数字。
3. **多进程评估被系统拒绝**。评估脚本启动多进程时报权限错误,
   改用单进程运行,结果一致。
4. **数据增强的领域约束**。交通标志不能做水平翻转——"向左急弯"翻转后
   会变成"向右急弯",标签与图片不再对应。这类约束必须结合业务判断,
   不能照搬通用图像增强方案。
