## 10-12

### 完成的事情

1. **确定选题**。结合本人智能车竞赛的经历,选定交通标志识别方向,
   数据集采用 GTSRB;理由是交通标志识别属于智能车视觉感知的基础任务,
   同时这是一个自主选题,不属于考核给出的三个参考项目方向。

2. **环境搭建**。硬盘上原有的是 Python 3.14,而 PyTorch 当时没有对应的安装包,
   因此用 uv 单独建了 Python 3.12 的项目环境。显卡是 RTX 5060(Blackwell 架构,
   算力 sm_120),必须使用 CUDA 12.8 及以上的 PyTorch 构建版本,
   所以在 `pyproject.toml` 里单独配置了 PyTorch 官方 CUDA 12.8 源。
   写完自检脚本 `scripts/check_env.py`,确认显存、算力、前向反向都正常。

3. **数据获取**。下载 GTSRB 训练集(26640 张)与测试集(12630 张),
   三个压缩包全部通过官方 MD5 校验。

4. **数据统计分析**。用 Pandas 汇总 43 个类别的标注文件,得到两个结论:
   类别不平衡(每类 150~1500 张,相差 10 倍,19 个类别不足均值一半);
   图片尺寸不统一(中位数仅 43 像素,82.1% 的图片短边不足 64 像素)。
   据此确定统一输入尺寸为 64x64,并把类别不平衡做成一组对照实验。

5. **手写 ResNet**。自己实现基础残差块与网络主体,未调用现成模型。
   针对 64x64 的小尺寸输入,去掉了官方版本开头用于降采样的 7x7 卷积与最大池化。
   模型参数量 11.19M。

6. **训练流程**。实现训练与评估循环、余弦学习率、按验证准确率保存最佳权重、
   训练曲线绘制。基线实验 20 轮,耗时 15 分钟,验证集准确率 100%。

7. **对照实验**。完成四组实验(基线、关闭数据增强、类别加权、去掉跳跃连接),
   在官方测试集上统一评估:基线 98.71%,关闭增强 97.92%,
   类别加权 98.26%,去掉跳跃连接 98.65%。

8. **推理与可视化**。实现对新图片的分类预测(输出 top-3 与中文含义)
   与 Grad-CAM 热力图。

### 遇到的问题

1. **git 推送被重置**。浏览器能正常访问 GitHub,但 git 推送报
   `Connection was reset`。原因是 git 不读取 Windows 的系统代理设置,
   而本机需要通过本地代理才能连上 GitHub。解决办法:只给 github.com
   配置代理,避免影响国内仓库。

2. **数据集下载卡死**。torchvision 自带的下载函数长时间停在 0 字节,
   改用 curl 后速度达到 17 MB/s。教训是遇到网络类工具不要死等,及时换方案。

3. **检查点加载失败**。PyTorch 2.6 起 `torch.load` 默认只信任张量与基本类型,
   而检查点里存了 numpy 标量,导致加载被拒绝。解决办法是保存时显式转成
   Python 原生类型,并在加载时保留安全模式优先、异常时回退的处理。

4. **消融实验的模型结构不匹配**。去掉跳跃连接的模型没有 1x1 投影层,
   加载权重时报键名缺失。解决办法是让加载函数根据权重里有没有 `downsample`
   自动判断结构。

5. **数据增强的领域约束**。交通标志不能做水平翻转——"向左急弯"翻转后
   会变成"向右急弯",标签与图片不再对应。这类约束必须结合业务判断,
   不能照搬通用图像增强方案。

## 10-13

### 完成的事情

1. **补充深层网络对照实验**。18 层网络上"去掉跳跃连接"的最终精度只差
   0.06 个百分点,不足以说明问题。因此给训练脚本增加了可配置的网络深度,
   在 34 层上重做对照。结果是:稀有类别平均准确率相差 6.28 个百分点,
   末轮验证损失相差约 5 倍,第 3 轮验证准确率相差 22.7 个百分点。
   同时发现两组 34 层实验的整体准确率几乎相同,说明只看总指标会掩盖问题。

2. **修复对比图的类别筛选错误**。绘制"最稀少 15 个类别"时误用了固定的
   类别编号 0-14,而这批编号里混着样本最多的类别,会导致结论相反。
   改为按样本数排序后动态选取,并在报告中核对了两组数字。

3. **撰写项目说明文档**。包括选题说明、数据集统计、技术方案、
   六个实验组的结果与分析、创新点、局限与改进方向。
