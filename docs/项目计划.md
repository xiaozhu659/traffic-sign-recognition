# 项目计划

## 一、选题

**基于手写 ResNet 的交通标志识别**

数据采用德国交通标志识别基准 GTSRB(43 类,训练 26640 张 / 测试 12630 张,
合计 39270 张)。选题动机:交通标志识别是自动驾驶与智能车视觉感知的基础任务,
与本人的智能车竞赛经历直接相关;同时这是一个自主选题,
不属于考核给出的三个参考项目方向。

## 二、考核要求对照

| 考核要求 | 本项目的落地方式 |
| --- | --- |
| Python + NumPy + Pandas + Matplotlib 处理与分析数据 | 用 Pandas 统计每类样本数,用 NumPy 做尺寸统计与归一化,用 Matplotlib 出分布图与训练曲线 |
| 手写 ResNet 完成图像分类 | 自己实现残差块(BasicBlock)与 ResNet 主体,不调用现成模型 |
| 用 PyTorch 训练并展示预测结果 | 完整训练流程 + 推理脚本,对新图片输出 top-3 预测与中文含义 |
| 迁移学习(了解基本思想) | 在文档中讨论其与从零训练的差异 |
| 仓库持续提交、保留真实开发历史 | 按阶段拆分提交,每完成一个模块提交一次 |
| 一份文档说明 | 项目说明文档(含个人感悟) |
| 一个运行视频 | 录屏演示数据统计、训练过程与推理结果 |

## 三、创新点

1. **类别不平衡的量化分析**:GTSRB 每类样本数从 150 到 1500 不等(相差 10 倍),
   对比基线与类别加权损失两种方案,用测试集数据说明收益与代价。
2. **残差连接的消融实验**:搭建去掉跳跃连接的对照组,
   从收敛速度与最终损失两个角度说明残差结构的作用。
3. **可演示的推理程序**:输入任意路牌照片,输出 top-3 类别、中文含义与置信度。
4. **Grad-CAM 可视化**:查看模型关注区域,验证其判断依据是否合理。
