# 实验结果

## 一、统一实验设置

为了保证可比性,四组实验除被考察的变量外,其余设置完全一致:

| 项目 | 设置 |
| --- | --- |
| 模型 | 手写 ResNet-18,参数量约 11.19 M |
| 输入尺寸 | 64x64(依据数据统计结果确定) |
| 训练轮次 | 20 |
| 批大小 | 128 |
| 优化器 | AdamW,lr=1e-3,weight_decay=5e-4 |
| 学习率调度 | 余弦退火 |
| 数据划分 | 训练集 23976 张,验证集 2664 张(按类别分层抽样) |
| 最终评估 | 官方测试集 12630 张,仅评估一次 |

## 二、测试集结果

| 实验 | 测试准确率 | 最稀少 15 类平均 | 最差类别准确率 |
| --- | --- | --- | --- |
| 基线(完整配置) | **98.71%** | 98.33% | 75.00% |
| 关闭数据增强 | 97.92% | 94.74% | 66.67% |
| 类别加权损失 | 98.26% | 99.04% | 75.00% |
| 去掉跳跃连接 | 98.65% | 99.41% | 79.17% |

## 三、收敛速度

最终精度接近时,收敛速度的差异更能说明问题:

| 实验 | 第 1 轮验证准确率 | 第 3 轮 | 第 5 轮 | 达到 99% 所需轮次 |
| --- | --- | --- | --- | --- |
| 基线 | 66.67% | 98.76% | 98.76% | **4** |
| 关闭数据增强 | 85.47% | 97.45% | 99.32% | 4 |
| 去掉跳跃连接 | 38.74% | 95.23% | 95.01% | **8** |
| 类别加权损失 | 26.99% | 82.77% | 98.01% | 8 |

## 四、结论与分析

### 1. 数据增强确实有效,而且收益集中在稀有类别

关闭增强后,验证集第 1 轮就有 85.47% 的准确率,比基线的 66.67% 高出一大截——
因为图片不再被随机裁剪和扰动,模型记住训练样本容易得多。但到了测试集上,
它的整体准确率反而低了 0.79 个百分点,样本最少的 15 个类别更是低了 3.59 个百分点。

这是典型的过拟合表现:**训练时看起来更好,泛化能力更差**。
增强带来的多样性对样本稀缺的类别帮助最大,这一点与开头的类别分布统计吻合。

### 2. 类别加权是整体精度与稀有类别之间的权衡

加权后,最稀少 15 类的平均准确率从 98.33% 提升到 99.04%,
但整体准确率从 98.71% 下降到 98.26%。原因是加权相当于提高了稀有类别
在损失中的权重,模型为照顾它们而牺牲了一部分常见类别的表现。

这说明**没有任何一种不平衡处理策略是无代价的**,选择哪一种取决于业务更在意
整体指标还是少数类别的召回。交通标志识别中,稀有标志(如注意冰雪、环岛)
漏检的后果往往更严重,因此在这种场景下更值得牺牲一点整体精度。

### 3. 残差连接的价值体现在"收敛更快"而不是"精度更高"

去掉跳跃连接后,测试准确率只下降了 0.06 个百分点(12630 张里约 8 张),
单看这个数字会得出"残差连接没用"的错误结论。但把训练过程摊开看:

* 第 1 轮验证准确率 38.74%,几乎只有基线(66.67%)的一半;
* 达到 99% 需要 8 轮,而基线只要 4 轮;
* 训练结束时的验证损失约为基线的 3 倍(0.002 对 0.0006)。

也就是说,**在 18 层的浅网络上,残差连接的收益主要表现为优化更容易、
收敛更快、最终损失更低,而不是最终分类精度更高**。这与 ResNet 论文的原始观察一致:
原作者对比 18 层与 34 层的普通网络时发现,层数增加反而使训练误差变大,
而残差结构能够消除这个退化现象;深度越深,残差连接的作用越明显。

本项目的网络只有 18 层,加上 GTSRB 本身是一个相对简单的任务(20 轮就接近饱和),
两者叠加使得两个版本在最终精度上难分伯仲。若要进一步验证这个结论,
可以把深度加到 34 层或 50 层后再做一次对照,观察差距是否随深度扩大。
这属于后续可以继续做的延伸实验,本次受时间限制未展开。

### 4. 少数类别是共同短板

从逐类别准确率看,四个实验都在类别 21(连续弯路)、30(注意冰雪)、
40(环岛行驶)上出现明显下降,其中关闭增强的版本在类别 21 上只有 66.67%。
这些标志的共同点是训练样本少、图案本身相似度高(都是三角形警告标志,
内部图形在低分辨率下难以区分)。

## 五、复现方式

```bash
uv run scripts/train.py --tag baseline --epochs 20
uv run scripts/train.py --tag no-augment --no-augment --epochs 20
uv run scripts/train.py --tag class-weights --class-weights --epochs 20
uv run scripts/train.py --tag no-skip --no-skip --epochs 20

uv run scripts/evaluate.py --tags baseline no-augment class-weights no-skip --num-workers 0
uv run scripts/compare_runs.py
```
